# EOP Seats Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The panel counts EOP seats for mail node mailboxes (used and free), refuses to create or restore a node mailbox without a free seat, makes a mailbox pending deletion read-only and frees its seat at once, and lets anyone ask for more seats (manual provider only).

**Architecture:** A new service `services/mailNode/eopSeats.js` owns the count: purchased seats come from Graph `GET /subscribedSkus` (`EOP_ENTERPRISE` `prepaidUnits.enabled`, read by a tenant job and stored in `integration_config` row `mail_node_eop_seats`) or from the manual `licenses` field of the EOP settings; used seats are node mailbox rows without a pending deletion plus in-flight creation reservations (table `mail_node_seat_reservations`), counted under a transactional advisory lock. A deletion request makes the mailbox read-only: the recipient mirror drops its tenant contact (domain sync job queued at request time), the send route, the send job and inbox rule forwards refuse it, and (if the research step allows) a per-mailbox Sieve filter on mailcow refuses local delivery. `services/mailNode/seatProvider.js` records seat requests (`manual`), which close by themselves once the purchased number grows.

**Tech Stack:** Node 22 ESM, Express 5, PostgreSQL (PGlite in tests), Vitest; React 19 + Vite, `node --test` with JSDOM; mailcow API; Microsoft Graph through the tenant driver.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-10-07-eop-seats-design.md`. Where this plan and the spec disagree, the spec wins; the deviations below are deliberate and listed for the owner.
- The screen shows only "used" and "free" ("В панели только «занято» и «свободно»"); the purchased number is never shown and never sent by `GET /api/mail-node/seats`.
- Purchased = `prepaidUnits.enabled` of `skuPartNumber == "EOP_ENTERPRISE"` (skuId `45a2423b-e884-448d-a831-d9e139c52d2f`); `consumedUnits` is not used for counting. Graph application permission `LicenseAssignment.Read.All`.
- Read cadence: every 6 hours (tenant poll), on "Reconcile" ("Сверить"), and after a manual seat request. A failed read keeps the last known number; older than 3 days -> warning in "Mail node" and an alert.
- Manual mode (tenant not configured, no tenant driver, or `TENANT_DRIVER=fake`): purchased = EOP settings field `licenses`. TERRL takes the same purchased number.
- Free = purchased - used, not below 0. Purchased < used: existing mailboxes untouched, no new ones, alert.
- A deletion request frees the seat at once; cancelling it takes one seat (refused at 0).
- Aliases take no seat.
- `seatProvider`: one action "request N seats"; only `manual` (journal `mail_node.seats_requested`, alert, visible in "Mail node", closes by itself when purchased grows by N). No vendor integrations (SoftwareOne, Insight).
- Tenant work never runs on an HTTP request's path (`services/tenant/driver.js` header, AGENTS.md map): the tenant recipient is removed and re-added by the domain sync job, queued at request and cancel time.
- mailcow is driven only through its API; never change mailcow's own code or configuration files.
- Migration: `backend/migrations/0095_eop_seats.sql`, forward only.
- Code, comments, commits in English; operator and user docs in Russian; every UI string in both `frontend/src/locales/en.json` and `ru.json` with identical keys.
- Tests: backend `cd backend && npx vitest run <file>` (PGlite tests are `*.pglite.test.js`); frontend `cd frontend && node --test <file>`. Full gates at the end: `cd backend && npm test && npm run lint && npm run lint:plugins`; `cd frontend && npm test && npm run lint && npm run build`.
- PGlite is one connection: inside `withTransaction` use only the transaction client, never the global `query` (it would wait on the open transaction forever). The "two parallel creations" test proves only one wins; the lock itself is asserted by a mock-level test that the transaction starts with `pg_advisory_xact_lock`.
- Commits as `wyrtensi`, Conventional Commits, no co-author lines, no emoji.

## Deliberate defaults (owner to confirm; see the report)

1. **Recipient removal at request time goes through the domain sync job**, not a direct EXO call (AGENTS.md forbids tenant work on a request's path). `removeRecipientBeforeDelete` stays in `BEFORE_NODE_DELETE` as an idempotent guard (a contact already gone is fine), so the "EOP rejects before the node forgets" invariant still holds if the tenant was down.
2. **Tenant connected but no successful Graph read yet** (first poll, permission not granted): the manual `licenses` number is used with a "not reconciled yet" note; with neither, purchased is unknown and creation is refused (`seats_unknown`).
3. **Anyone signed in may press "Request seats"** (creation is open to every user; manual mode only journals and alerts).
4. **Inbox rule forwards from a read-only mailbox are skipped** ("отправить нельзя").
5. **Requests close individually**: a request closes once purchased >= purchased-at-request + N.

```sql
-- EOP seats (docs/superpowers/specs/2026-10-07-eop-seats-design.md, services/mailNode/eopSeats.js).
-- A seat is taken by every mail node mailbox without a pending deletion (email_accounts.mail_node AND
-- delete_after IS NULL) and by every creation in flight: a reservation row taken under the seats
-- lock before the node is asked for the mailbox and removed in the transaction that inserts the
-- account row. A reservation past expires_at (a creation that stopped half way) counts no more.
CREATE TABLE IF NOT EXISTS mail_node_seat_reservations (
  id bigserial PRIMARY KEY,
  email text NOT NULL,
  created_at timestamptz NOT NULL DEFAULT NOW(),
  expires_at timestamptz NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_mail_node_seat_reservations_expires ON mail_node_seat_reservations (expires_at);

-- Requests for more seats (services/mailNode/seatProvider.js). provider 'manual': an administrator
-- buys them from the reseller; a request closes by itself once the purchased number reaches
-- purchased_at_request + seats (NULL counts as 0). The requester's email is copied so the list
-- still names a user who is gone.
CREATE TABLE IF NOT EXISTS mail_node_seat_requests (
  id bigserial PRIMARY KEY,
  provider text NOT NULL,
  seats integer NOT NULL CHECK (seats > 0),
  purchased_at_request integer,
  requested_by uuid REFERENCES users(id) ON DELETE SET NULL,
  requested_by_email text,
  requested_at timestamptz NOT NULL DEFAULT NOW(),
  closed_at timestamptz
);
CREATE INDEX IF NOT EXISTS idx_mail_node_seat_requests_open
  ON mail_node_seat_requests (requested_at) WHERE closed_at IS NULL;
```

`backend/src/services/mailNode/eopSeats.js`:

```js
import { query, withTransaction } from '../db.js';
import { getEopSettings, tenantConfigured } from './eopSettings.js';
import { getTenantDriver } from '../tenant/driver.js';

// EOP seats (docs/superpowers/specs/2026-10-07-eop-seats-design.md): every mail node mailbox is
// protected by EOP and needs one EOP licence. The screen shows used and free only.
//
// Purchased: prepaidUnits.enabled of the EOP_ENTERPRISE subscription in Graph GET /subscribedSkus
// (right LicenseAssignment.Read.All), read by the tenant jobs (services/tenant/tenantJobs.js: the
// poll every 6 hours, "Reconcile", after a seat request) and kept in integration_config
// 'mail_node_eop_seats' ({ at, ok, purchased, found, skus, error, errorAt }); a failed read keeps
// the last good number with the error beside it, stale after 3 days. Without a tenant driver, with
// TENANT_DRIVER=fake or with the tenant not configured, the administrator enters it: the EOP
// settings field `licenses`, which the TERRL budget takes too. consumedUnits is not used: mailboxes
// are mail contacts in the tenant (D-5), which take no licence assignment.
//
// Used: node mailbox rows without a pending deletion (a deletion request frees the seat at once)
// plus creations in flight (mail_node_seat_reservations, migration 0095). Creation and the cancel of
// a deletion take a seat under one transactional advisory lock, so only one request gets the last
// seat.

export const EOP_SKU_PART_NUMBER = 'EOP_ENTERPRISE';
export const SEATS_PROVIDER = 'mail_node_eop_seats';
const SEATS_LOCK = 'mail_node:eop_seats';
export const SEATS_STALE_MS = 3 * 24 * 60 * 60 * 1000;
export const RESERVATION_MINUTES = 10;
export const MAX_SEAT_REQUEST = 1000;

const whole = (value) => (Number.isInteger(value) && value >= 0 ? value : 0);

// The EOP subscriptions of a GET /subscribedSkus answer: { found, purchased, skus }. Several EOP
// subscriptions add up; none means 0 seats.
export function parseSubscribedSkus(answer) {
  const rows = Array.isArray(answer?.value) ? answer.value : [];
  const eop = rows.filter((row) => String(row?.skuPartNumber ?? '').toUpperCase() === EOP_SKU_PART_NUMBER);
  if (!eop.length) return { found: false, purchased: 0, skus: [] };
  const skus = eop.map((row) => ({
    skuId: row.skuId ?? null,
    appliesTo: row.appliesTo ?? null,
    capabilityStatus: row.capabilityStatus ?? null,
    enabled: whole(row.prepaidUnits?.enabled),
    suspended: whole(row.prepaidUnits?.suspended),
    warning: whole(row.prepaidUnits?.warning),
    consumedUnits: whole(row.consumedUnits),
  }));
  return { found: true, purchased: skus.reduce((sum, sku) => sum + sku.enabled, 0), skus };
}

// 'graph' when the tenant gives the number (a real driver and the four tenant fields), else 'manual'.
export function seatSource(eop, driver) {
  return driver && driver.kind !== 'fake' && tenantConfigured(eop ?? {}) ? 'graph' : 'manual';
}

// The purchased number: { purchased, mode, source, at, stale, notReconciled, error }. mode: where it
// should come from; source: where it came from. In graph mode before the first good read the manual
// number stands in (notReconciled).
export function purchasedSeats({ eop, read, source, now = Date.now() }) {
  const manual = Number.isInteger(eop?.licenses) ? eop.licenses : null;
  if (source !== 'graph') {
    return { purchased: manual, mode: 'manual', source: 'manual', at: null, stale: false, notReconciled: false, error: null };
  }
  const at = Date.parse(read?.at ?? '');
  const error = read?.ok === false ? (read.error ?? null) : null;
  if (!Number.isInteger(read?.purchased) || !Number.isFinite(at)) {
    return { purchased: manual, mode: 'graph', source: 'manual', at: null, stale: false, notReconciled: true, error };
  }
  return { purchased: read.purchased, mode: 'graph', source: 'graph', at: read.at, stale: now - at > SEATS_STALE_MS, notReconciled: false, error };
}

export async function getSeatRead(db = { query }) {
  const { rows } = await db.query('SELECT config FROM integration_config WHERE provider = $1', [SEATS_PROVIDER]);
  return rows[0]?.config ?? null;
}

export async function saveSeatRead(read, db = { query }) {
  await db.query(`
    INSERT INTO integration_config (provider, config) VALUES ($1, $2)
    ON CONFLICT (provider) DO UPDATE SET config = EXCLUDED.config, updated_at = NOW()
  `, [SEATS_PROVIDER, read]);
}

// The purchased number now. Reads the settings and the stored read with the global query: never
// call it inside a transaction.
export async function seatSupply({ eop = null, now = Date.now() } = {}) {
  const settings = eop ?? await getEopSettings();
  const source = seatSource(settings, getTenantDriver());
  const read = source === 'graph' ? await getSeatRead() : null;
  return purchasedSeats({ eop: settings, read, source, now });
}

export async function lockSeats(client) {
  await client.query('SELECT pg_advisory_xact_lock(hashtext($1))', [SEATS_LOCK]);
}

export async function countUsed(db = { query }) {
  const { rows: [row] } = await db.query(`
    SELECT (SELECT count(*)::int FROM email_accounts WHERE mail_node AND delete_after IS NULL)
         + (SELECT count(*)::int FROM mail_node_seat_reservations WHERE expires_at > NOW()) AS used`);
  return Number(row?.used ?? 0);
}

export async function openSeatRequests(db = { query }) {
  const { rows } = await db.query(`
    SELECT id, provider, seats, purchased_at_request, requested_by_email, requested_at
      FROM mail_node_seat_requests WHERE closed_at IS NULL ORDER BY requested_at, id`);
  return rows.map((row) => ({
    id: Number(row.id), provider: row.provider, seats: row.seats, purchasedAtRequest: row.purchased_at_request,
    requestedBy: row.requested_by_email ?? null, requestedAt: row.requested_at,
  }));
}

// Everything the screens and the alerts need: the purchased number with where it came from, used,
// free (null while purchased is unknown), over (purchased below used) and the open requests.
export async function getSeats({ now = Date.now() } = {}) {
  const [supply, used, requests] = await Promise.all([seatSupply({ now }), countUsed(), openSeatRequests()]);
  const known = supply.purchased != null;
  return {
    ...supply, used, free: known ? Math.max(0, supply.purchased - used) : null, over: known && supply.purchased < used, requests,
  };
}

// Takes a seat for a creation in flight: { reservationId } or { error: seats_unknown | no_free_seats }.
// The caller removes the reservation in the transaction that inserts the account row, or gives it
// back (releaseReservation) when the creation fails; one that is never removed expires.
export async function reserveSeat(email) {
  const { purchased } = await seatSupply();
  if (purchased == null) return { error: 'seats_unknown' };
  return withTransaction(async (client) => {
    await lockSeats(client);
    await client.query("DELETE FROM mail_node_seat_reservations WHERE expires_at < NOW() - interval '1 day'");
    if (purchased - await countUsed(client) < 1) return { error: 'no_free_seats' };

  });
}

export async function releaseReservation(id, db = { query }) {
```

```js
// Someone cancels a pending deletion: the mailbox takes an EOP seat again (services/mailNode/
// eopSeats.js; purchased: the number now, null while unknown), so the check and the change run
// under the seats lock in one transaction. The request (reason included) is cleared from the row;
// the journal keeps it. Refused once the job has claimed the row (deletion_started_at), stale claim
// included: the node mailbox may be gone already. Answers { deleteAfter, reason } (what was set) or
// { error }: account_not_found, deletion_not_requested, deletion_in_progress, seats_unknown,
// no_free_seats.
export async function cancelDeletion({ accountId, purchased }) {
  return withTransaction(async (client) => {
    await lockSeats(client);
    const { rows: [found] } = await client.query(
      'SELECT delete_after, deletion_reason, deletion_started_at FROM email_accounts WHERE id = $1 FOR UPDATE', [accountId],
    );
    if (!found) return { error: 'account_not_found' };
    if (!found.delete_after) return { error: 'deletion_not_requested' };
    if (found.deletion_started_at) return { error: 'deletion_in_progress' };
    if (purchased == null) return { error: 'seats_unknown' };
    if (purchased - await countUsed(client) < 1) return { error: 'no_free_seats' };
    await client.query(`
      UPDATE email_accounts
         SET deletion_requested_at = NULL, deletion_requested_by = NULL, deletion_requested_by_email = NULL,
             deletion_reason = NULL, delete_after = NULL, deletion_attempts = 0, deletion_next_attempt_at = NULL,
             deletion_last_error = NULL
       WHERE id = $1`, [accountId]);
    return { deleteAfter: found.delete_after, reason: found.deletion_reason ?? null };
  });
}
```

```js
// only provider today is 'manual': the request is kept (mail_node_seat_requests, migration 0095)
// and journaled (mail_node.seats_requested), the mail node alerts raise eop_seats_requested, an

  name: 'manual',
  async request({ seats, purchased, actor }) {
    const { rows: [row] } = await query(`
      INSERT INTO mail_node_seat_requests (provider, seats, purchased_at_request, requested_by, requested_by_email)
      VALUES ('manual', $1, $2, $3, (SELECT COALESCE(NULLIF(email, ''), username) FROM users WHERE id = $3))
      RETURNING id, seats, requested_at`, [seats, purchased, actor?.userId ?? null]);

  },

  return manual;

// Anyone signed in may ask (the add form is open to everyone). Answers { request } or { error:
// 'seat_count_invalid' }. With the tenant giving the number, Graph is read again at once.
export async function requestSeats({ seats }, actor) {
  const count = parseWholeNumber(seats, 1, MAX_SEAT_REQUEST);
  if (count == null) return { error: 'seat_count_invalid' };
  const supply = await seatSupply();
  const provider = getSeatProvider();
  const request = await provider.request({ seats: count, purchased: supply.purchased, actor });
  recordAudit(auditOf(actor, {
    action: 'mail_node.seats_requested', details: { seats: count, provider: provider.name, purchased: supply.purchased },
  }));
  if (supply.mode === 'graph') {
    await enqueueTenantJob(TENANT_JOB_KINDS.seats, jobBy(actor))
      .catch((err) => console.error(`EOP seats read could not be queued: ${err?.code || err?.message}`));
  }
  return { request };
}
```

```jsx
import { useState } from 'react';
import { useTranslation } from 'react-i18next';
import { api } from '../utils/api.js';
import { formatDateTime } from '../utils/formatDate.js';
import { mailNodeErrorDetail, mailNodeErrorKey, seatRequestError, seatsView } from '../utils/mailNode.js';

const noteStyle = { fontSize: 11, color: 'var(--text-tertiary)', lineHeight: 1.5 };
const warnStyle = { ...noteStyle, color: 'var(--amber)' };
const buttonStyle = {
  padding: '5px 10px', borderRadius: 6, fontSize: 12, fontWeight: 500, border: '1px solid var(--border)',
  background: 'transparent', color: 'var(--text-primary)', cursor: 'pointer',
};
const inputStyle = {
  width: 70, padding: '5px 8px', background: 'var(--bg-tertiary)', border: '1px solid var(--border)',
  borderRadius: 6, color: 'var(--text-primary)', fontSize: 12,
};

// The EOP seats counter (EOP seats design, 2026-10-07): used and free only (the purchased number is
// never shown), when Microsoft was last asked, "Reconcile" (administrators, while the tenant gives
// the number), "Request seats" and the open requests. compact: the one line the add form and the
// pending deletion notice show, with "Request seats" only when no seat is free. seats: GET
// /api/mail-node/seats, loaded by the caller; onChanged() makes the caller load it again.
export default function MailNodeSeats({ seats, compact = false, isAdmin = false, onChanged = () => {} }) {
  const { t } = useTranslation();
  const [asking, setAsking] = useState(false);
  const [count, setCount] = useState('1');
  const [busy, setBusy] = useState(false);
  const [error, setError] = useState(null);
  const [notice, setNotice] = useState(null);
  const view = seatsView(seats);
  if (!view) return null;

  const fail = (err) => setError({ key: mailNodeErrorKey(err?.code), detail: mailNodeErrorDetail(err) });
  const run = async (fn, done) => {
    setBusy(true);
    setError(null);
    setNotice(null);
    try {
      await fn();
      setNotice(done);
      onChanged();
    } catch (err) {
      fail(err);
    } finally {
      setBusy(false);
    }
  };
  const sendRequest = () => {
    const problem = seatRequestError(count);
    if (problem) {
      setError({ key: problem, detail: '' });
      return;
    }
    run(async () => {
      await api.mailNode.requestSeats(Number(count));
      setAsking(false);
    }, 'admin.mailNode.seats.requestSent');
  };
  const reconcile = () => run(() => api.mailNode.checkSeats(), 'admin.mailNode.seats.checkQueued');

  const none = view.known && view.free === 0;
  const showRequest = !compact || !view.canTake;
  return (
    <div data-eop-seats data-seats-free={view.known ? String(view.free) : 'unknown'} style={{ marginTop: compact ? 8 : 0 }}>
      <div style={{ fontSize: compact ? 12 : 13, fontWeight: 600, color: none ? 'var(--red)' : 'var(--text-primary)' }}>
        {view.known ? t('admin.mailNode.seats.counter', { used: view.used, free: view.free }) : t('admin.mailNode.seats.unknown')}
      </div>
      {!compact && seats.source === 'graph' && seats.checkedAt && (
        <div style={noteStyle}>{t('admin.mailNode.seats.checkedAt', { at: formatDateTime(seats.checkedAt) })}</div>
      )}
      {!compact && seats.mode === 'manual' && <div style={noteStyle}>{t('admin.mailNode.seats.manual')}</div>}
      {!compact && seats.notReconciled && <div style={noteStyle}>{t('admin.mailNode.seats.notReconciled')}</div>}
      {!compact && seats.stale && (
        <div role="alert" style={warnStyle}>{t('admin.mailNode.seats.stale', { at: formatDateTime(seats.checkedAt) })}</div>
      )}
      {!compact && seats.over && <div role="alert" style={warnStyle}>{t('admin.mailNode.seats.over')}</div>}
      {!compact && seats.requests?.length > 0 && (
        <div data-seat-requests style={noteStyle}>
          {t('admin.mailNode.seats.openRequests')}
          <ul style={{ margin: '2px 0 0', paddingLeft: 18 }}>
            {seats.requests.map((r) => (
              <li key={r.id}>
                {t('admin.mailNode.seats.openRequest', {
                  seats: r.seats, by: r.requestedBy || t('admin.mailNode.someone'), at: formatDateTime(r.requestedAt),
                })}
              </li>
            ))}
          </ul>
        </div>
      )}
      {(showRequest || (!compact && isAdmin && seats.mode === 'graph')) && (
        <div style={{ display: 'flex', gap: 8, marginTop: 6, flexWrap: 'wrap', alignItems: 'center' }}>
          {!compact && isAdmin && seats.mode === 'graph' && (
            <button type="button" onClick={reconcile} disabled={busy} style={buttonStyle}>
              {busy ? t('admin.mailNode.seats.checking') : t('admin.mailNode.seats.check')}
            </button>
          )}
          {showRequest && !asking && (
            <button type="button" onClick={() => setAsking(true)} disabled={busy} style={buttonStyle}>
              {t('admin.mailNode.seats.request')}
            </button>
          )}
          {asking && (
            <>
              <label style={noteStyle}>
                {t('admin.mailNode.seats.requestCount')}{' '}
                <input inputMode="numeric" value={count} onChange={(e) => setCount(e.target.value)} style={inputStyle} />
              </label>
              <button type="button" onClick={sendRequest} disabled={busy} style={buttonStyle}>{t('admin.mailNode.seats.requestSend')}</button>
              <button type="button" onClick={() => setAsking(false)} disabled={busy} style={buttonStyle}>{t('common.cancel')}</button>
            </>
          )}
        </div>
      )}
      {notice && <div role="status" style={noteStyle}>{t(notice)}</div>}
      {error && <div role="alert" style={{ ...noteStyle, color: 'var(--red)' }}>{t(error.key)}{error.detail ? ` (${error.detail})` : ''}</div>}
    </div>
  );
}
```
